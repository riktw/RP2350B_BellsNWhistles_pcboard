## PCBoard for RP2350B BellsNWhistles

This contains the kicad files for a little board that turns the [RP2350B BellsNWhistles](https://github.com/riktw/RP2350B_BellsNWhistles) board into a small computer.
It has all the modern and some retro IO like:

- 3 x USB
- PS/2 for mouse and keyboard
- NES controller
- Audio via 3.5mm
- MicroSD for storage
- On board RTC

This board is tested and no bugs should remain in the latest version.
